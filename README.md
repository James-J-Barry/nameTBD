# nameTBD (working name: Firstmark)

A free, self-serve **provenance registry for games**, combined with structured **AI-usage disclosure** data. Indie developers can prove *"we showed this first"*, especially before release. Players can see how a game used AI, on the store pages where they already shop.

Firstmark doesn't sell games, and it never labels a game a copy. It records dated evidence for originals.
